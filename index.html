📤 Daten exportieren

Speichere alle deine Einnahmen, Ausgaben, Sparziele und Kategorien als JSON-Datei auf deinem Gerät. Lege sie anschließend in iCloud, Google Drive oder einem anderen sicheren Ort ab.

🗂️ Komplette App exportieren

Erstellt eine neue HTML-Datei mit all deinen Daten bereits eingebettet. Perfekt um das Tool auf ein anderes Gerät zu übertragen – einfach Datei öffnen, fertig.

📂 Daten importieren

Stelle ein vorhandenes JSON-Backup wieder her. Achtung: Die aktuellen Daten werden dabei überschrieben. Sichere vorher deine aktuellen Daten per Export.

⚠️ Daten zurücksetzen

Setzt alle Daten auf die Beispiel-Standardwerte zurück. Diese Aktion kann nicht rückgängig gemacht werden. Bitte vorher ein Backup erstellen!

🔄 Nach jedem Wechsel: JSON importieren
